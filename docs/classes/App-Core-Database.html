Clase Database - Gestión de conexión a base de datos usando patrón Singleton

Esta clase maneja la conexión única a la base de datos MySQL que almacena la información de las unidades para consultar la API de Wialon.

Utiliza el patrón Singleton para garantizar una única instancia de conexión durante todo el ciclo de vida de la aplicación, optimizando recursos.
